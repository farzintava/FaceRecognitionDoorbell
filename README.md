# Face Recognition Doorbell

## Description
A smart doorbell system using face recognition technology to identify visitors. Built with a Raspberry Pi, Flask, and OpenCV.

## Features
- Real-time face detection and recognition.
- Email notifications for recognized and unknown faces.
- Interactive web interface for managing known faces.
- Hardware interaction with button and LED.
- LCD display integration for status messages.

## Requirements
- Hardware: Raspberry Pi, Camera Module, Push Button, LED, LCD.
- Software: Python, Flask, OpenCV, Dlib, SQLite.
